# Отгрузка юридическим лицам. 5 дней

Два листа для менеджера по работе с клиентами.

Стажёр отмечает, что сделал сам. Наставник отмечает, что увидел, и ставит допуск.

Главное отличие от кассы и от монитора интернет-магазина: товар организации отдаём, когда на получателя есть доверенность и есть основание отгрузить. Основание одно из двух: счёт уже оплачен или в «Помощнике продаж» открыт остаток кредита и запрета отгрузки нет.
