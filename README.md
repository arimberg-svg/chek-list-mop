# Чек-лист на 5 дней. Менеджер по работе с клиентами

Отгрузка юридическим лицам в магазине. Рядом с частным покупателем на кассе и с заказом из монитора интернет-магазина.

Главное отличие: товар организации отдаём, когда на получателя есть доверенность и есть основание отгрузить. Основание одно из двух: счёт уже оплачен или в «Помощнике продаж» открыт остаток кредита и запрета отгрузки нет.
